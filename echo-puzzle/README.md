# 残響パズル

「残響パズル」は、PCブラウザで遊ぶ小さな2Dグリッドパズルゲームです。プレイヤーが動くと、1ターン遅れて残響が同じ移動を再現します。プレイヤーと残響を別々の位置へ誘導し、2つのスイッチを同時に押すとステージクリアです。

## ルール

- プレイヤーはグリッド上を上下左右に1マスずつ移動します。
- 移動後、残響は1ターン前のプレイヤーの移動を再現します。
- 壁にはプレイヤーも残響も入れません。
- 穴に入るとミスになり、そのステージをやり直します。
- 一方通行床は、床に描かれた矢印の向きにしか出られません。
- プレイヤーと残響が2つのスイッチを同時に押すとステージクリアです。
- 最終ステージをクリアするとゲームクリアです。

## 操作方法

- 矢印キー / WASD: 移動
- R: 現在ステージをリスタート
- ステージクリア後: 自動で次のステージへ進みます

## ファイル構成

```text
echo-puzzle/
├── index.html  # ゲーム画面のHTML
├── style.css   # 見た目とグリッド表示
├── script.js   # ゲームロジック、ステージ定義、入力処理
└── README.md   # ルール、操作、ステージ設計
```

## ステージ設計の狙い

1. **追従の基本**  
   壁や穴を使わず、残響が1ターン遅れて同じ移動をすることと、2つのスイッチを同時に押す目標を学びます。

2. **壁で距離を作る**  
   壁を回り込むことで、プレイヤーと残響の位置関係をずらし、同時押しに必要な間隔を作ることを学びます。

3. **穴を避ける**  
   穴を配置し、プレイヤーだけでなく残響の移動先も安全にする必要があることを学びます。

4. **一方通行床**  
   一方通行床から出られる方向が制限されることを学び、次の一手だけでなく残響の次の一手も考える練習をします。

5. **総合問題**  
   壁、穴、一方通行床を組み合わせ、残響との距離調整と安全なルート選びをまとめて使います。

## ローカルでの起動方法

ビルドやnpmは不要です。`index.html` をブラウザで直接開くか、任意で次のようなローカルサーバーから開けます。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/echo-puzzle/` を開きます。

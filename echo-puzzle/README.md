# 残響パズル

PCブラウザで遊ぶ、HTML/CSS/JavaScriptだけの小さな2Dパズルゲームです。プレイヤーが入力した移動を、1ターン遅れて「残響」が再現します。プレイヤーと残響で2つのスイッチを同時に押すとステージクリアです。

## ルール

- プレイヤーは上下左右に1マス移動します。
- 残響は、1ターン前にプレイヤーが入力した方向へ移動します。
- 壁に向かって入力するとプレイヤーはその場に留まりますが、1ターンは進みます。これを使って残響だけを動かせます。
- 壁にはプレイヤーも残響も入れません。
- 穴に入るとミスになり、そのステージをリスタートします。
- 一方通行床に乗っているときは、矢印方向にしか出られません。
- プレイヤーと残響が2つのスイッチを同時に踏むとクリアです。

## 操作方法

- 矢印キー / WASD: 移動
- R: 現在ステージをリスタート
- クリア後は自動で次のステージへ進みます。

## ファイル構成

```text
echo-puzzle/
├── index.html
├── style.css
├── script.js
└── README.md
```

## ステージ設計

| ステージ | 狙い | テスト済み解法 |
| --- | --- | --- |
| 1 | 右スイッチで待機し、残響を左スイッチへ乗せる基本を学ぶ | `RR` |
| 2 | 壁で待機ターンを作ることを学ぶ | `RR` |
| 3 | 穴を避け、残響も安全な道だけを通すことを学ぶ | `RR` |
| 4 | 一方通行床から出る方向の制限を学ぶ | `RRR` |
| 5 | 壁・穴・一方通行床を組み合わせた総合問題 | `RRR` |

`R` は右入力です。たとえばステージ1は「右、右」でクリアできます。1回目の右入力でプレイヤーが右スイッチへ乗り、2回目の右入力は壁に当たって待機になります。その間に残響が1ターン遅れで左スイッチへ乗ります。

## クリア可能性テスト

実装したゲームロジックと同じ関数を使って、各ステージの `testSolution` が本当にクリアになるかをNodeで確認できます。

```bash
node -e "const { runStageSelfTests } = require('./echo-puzzle/script.js'); const results = runStageSelfTests(); console.log(JSON.stringify(results, null, 2)); if (!results.every((r) => r.clear)) process.exit(1);"
```

## ローカル起動

ビルドやnpmは不要です。`index.html` をブラウザで直接開くか、リポジトリルートで次を実行してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/echo-puzzle/` を開きます。

# AGENTS.md

## Repository purpose

This repository is a personal AI coding lab. It contains multiple small coding projects used for experimenting with AI-assisted development.

## Structure

- mini_ironclad_spire_ai/: A simplified Slay the Spire-like card battle environment and AI training project.

## General instructions for Codex

- Prefer simple, readable Python code.
- Keep each project self-contained inside its own directory.
- Do not move files between projects unless explicitly asked.
- When changing behavior, update the relevant README.md.
- When adding code, include a simple way to run or test it.
- Avoid adding large generated files, caches, virtual environments, or dependency folders to Git.

## Python conventions

- Use Python 3.
- Prefer standard library first.
- Use requirements.txt when external packages are needed.
- Keep random behavior reproducible with a seed when possible.

## Testing

When tests exist, run pytest.

If tests do not exist yet, explain what manual check was performed.
